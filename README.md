# Margin Guard for WooCommerce

**Stop coupons from discounting products below your minimum gross margin.**

Margin Guard is a WooCommerce profit-protection plugin for stores that know product cost and want a hard floor under discounting.

## The problem

A coupon can increase revenue while quietly turning a low-margin order into a bad sale. Margin Guard checks the discount against product cost and your minimum gross-margin target, then caps the coupon before it crosses that floor.

Example: if a product costs **$80** and the store requires a **20% gross margin**, revenue must stay at **$100 or more**. Margin Guard prevents a coupon from pushing that item below the floor.

## Free Lite version

The Lite plugin is fully functional and does not expire.

- Set one global minimum gross-margin floor.
- Add a per-unit cost of goods value to products.
- Automatically cap WooCommerce coupon discounts when necessary.
- HPOS and Cart/Checkout Blocks compatibility declared.
- No remote calls required for the margin calculation.

**Download:** `margin-guard-for-woocommerce-v1.0.2.zip` in this branch.
